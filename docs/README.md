# Documentation

Supporting documents are grouped by their intended reader:

- `docs/human/`: reserved and empty for now. Its purpose remains to be decided; the initial idea is a human-readable account of development, architecture, decisions and trade-offs.
- [Agent documentation](agent/): continuation context and work evidence. Start with the [checkpoint](agent/checkpoint.md); see the [development log](agent/dev.log.md) and [evaluation analysis](agent/evaluation-priorities.md), and [planned testing strategy](agent/testing-strategy.md) when needed.

Required submission documents stay at the root: [README.md](../README.md) contains project status and pending setup sections; [DECISIONS.md](../DECISIONS.md) is a working outline; [AI_USAGE.md](../AI_USAGE.md) is a working source log. The original assignment is preserved verbatim in [ASSIGNMENT.md](../ASSIGNMENT.md). Runnable instructions will be completed and verified when the app is implemented.

Create additional documents only when useful. No version or release hierarchy is required.
